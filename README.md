# DockDrop

DockDrop is a macOS menu bar app that shows a floating app shelf while you drag files, then activates target apps when you hover their icon.
Built this because native macOS drag/drop files is not intuitive nor confortable.
![DockDrop demo](docs/media/built-in-retina-display.gif)

## Build

```bash
swift build
swift run DockDrop
```
